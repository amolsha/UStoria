About UStoria

UStoria is a research-driven tool for evaluating the quality of user stories. It leverages the Quality User Story (QUS) framework and advanced LLMs to:

  • Assess individual user stories against 8 quality criteria
  • Provide reasoning for pass/fail evaluations
  • Suggest improved (repaired) user stories
  • Visualize aggregate results across datasets

This project is built with Flask, OpenAI API, and modern web technologies.
